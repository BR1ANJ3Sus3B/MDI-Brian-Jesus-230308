## Proyecto incluido

La carpeta `proyecto-movil` contiene una aplicación Flutter de tareas, **FastAPI o Node.js/Express** como alternativas de backend, PostgreSQL, MongoDB, Keycloak, Docker Compose, contrato OpenAPI, colección Postman y pruebas.

La ruta principal utiliza Windows y Android. Los servicios se ejecutan en Docker y Flutter se ejecuta en el dispositivo. Los capítulos explican la diferencia entre las configuraciones locales de laboratorio y un despliegue de producción.
