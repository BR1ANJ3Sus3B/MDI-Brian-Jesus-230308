# Índice del manual

**Manual de Instalación y Configuración del Entorno de Desarrollo para Aplicaciones Móviles Multiplataforma**

Lectura principal: Windows, PowerShell y Android. Completa primero las herramientas base, elige **FastAPI o Express**, configura la infraestructura y termina con la integración. PostgreSQL y MongoDB cumplen funciones distintas dentro del mismo ejercicio.
