Cada archivo E01–E24 de [evidence](../evidence/README.md) contiene objetivo, comando o acción, resultado esperado, espacio para captura y conclusión. Completa el resultado real; no marques éxito sin ejecutar la comprobación.

Usa nombres de captura como `E14-crear-tarea.png`. Antes de incluirlos, oculta tokens, contraseñas y datos personales. Puedes conservar material sensible temporal en `docs/evidence/private`, excluido de Git, y publicar solo versiones revisadas.

Una conclusión útil relaciona resultado con concepto: “La tarea permaneció al reiniciar porque el volumen conserva PostgreSQL”. Evita conclusiones genéricas como “todo salió bien”. Si eliges un solo backend, marca el otro módulo como “alternativa no elegida”.
