# 01. Objetivo y uso del manual

Al finalizar, el estudiante podrá preparar, explicar y verificar un entorno que conecta una aplicación Flutter con una API autenticada, PostgreSQL y MongoDB mediante Docker Compose. El trabajo incluye instalar herramientas, comprender su función y demostrar el flujo completo con evidencias propias.

## Cómo estudiar

1. Completa los capítulos 02–18 para preparar la computadora y comprender HTTP.
2. Elige el capítulo 19 (Python/FastAPI) o 21 (Node.js/Express). Lee el 20 en ambos casos.
3. Estudia los datos y la autenticación en 22–26.
4. Monta los servicios siguiendo 27–30.
5. Integra Flutter, prueba y entrega siguiendo 31–41.

Las herramientas se presentan con concepto, problema resuelto, ubicación arquitectónica, instalación, configuración, práctica, verificación y evidencia. Los capítulos conceptuales complementan las prácticas; no requieren instalar otro programa.

**Convenciones:** los comandos PowerShell parten de la carpeta indicada. `ID_DEL_DISPOSITIVO`, `TU_USUARIO` y los campos de portada se sustituyen por datos propios. Los archivos de código del proyecto sí están completos. Los resultados esperados no implican que una prueba se haya ejecutado.

La ruta principal prueba Android. Flutter permite otras plataformas, pero iOS exige macOS y Xcode para compilar; el login de este proyecto está configurado para Android. Usar Chrome con `flutter run` no sustituye esta prueba de autenticación móvil.

**Entrega:** repositorio, manual con portada, evidencias E01–E24 y demostración de tareas autenticadas. Consulta [el índice](../README.md) en cualquier momento.
