# 05. Objetivos

## Objetivo general

Instalar, configurar y validar un entorno reproducible para desarrollar una aplicación móvil multiplataforma con servicios REST, persistencia, autenticación y control de versiones.

## Objetivos específicos

- Configurar Flutter, Dart y Android SDK; interpretar `flutter doctor`.
- Crear y ejecutar una aplicación Android con Flutter.
- Consumir APIs y manejar carga, errores, JSON y tiempos de espera.
- Crear una API REST con FastAPI **o** Express.
- Utilizar PostgreSQL para relaciones y MongoDB para documentos de actividad.
- Implementar login con Keycloak y permisos mediante roles y propietario.
- Probar solicitudes con Postman y explorar el contrato OpenAPI mediante Swagger.
- Crear imágenes Docker y administrar servicios con Docker Compose.
- Utilizar Git para registrar cambios y GitHub para colaborar con ramas y Pull Requests.
- Presentar evidencias reproducibles sin divulgar contraseñas ni tokens.

El criterio de logro es funcional: cada estudiante debe poder explicar y demostrar el recorrido desde un toque en Flutter hasta la persistencia y la respuesta.
