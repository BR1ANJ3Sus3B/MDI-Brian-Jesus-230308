# 41. Glosario

| Concepto | Definición |
| --- | --- |
| API | Interfaz para que programas intercambien operaciones y datos. |
| REST | Estilo de arquitectura basado en recursos y una interfaz uniforme. |
| HTTP | Protocolo de solicitudes y respuestas. |
| HTTPS | HTTP protegido mediante TLS. |
| JSON | Formato textual de intercambio de datos. |
| JWT | Token con claims y firma verificable. |
| OAuth 2.0 | Marco de autorización delegada. |
| OpenID Connect | Protocolo de identidad sobre OAuth 2.0. |
| PKCE | Prueba que vincula el código de autorización con quien inició el flujo. |
| SDK | Conjunto de herramientas para desarrollar para una plataforma. |
| Framework | Estructura y herramientas para construir aplicaciones. |
| Runtime | Entorno que ejecuta un programa. |
| Endpoint | Dirección y operación accesible de una API. |
| Backend | Lógica y datos del lado servidor. |
| Frontend | Interfaz con la que interactúa el usuario. |
| ORM | Herramienta que relaciona objetos con datos relacionales. |
| SQL | Lenguaje de definición y consulta relacional. |
| NoSQL | Familia de modelos de datos no limitados al relacional. |
| BSON | Representación binaria de documentos usada por MongoDB. |
| Contenedor | Proceso aislado creado desde una imagen. |
| Imagen | Plantilla de un entorno de ejecución. |
| Volumen | Almacenamiento persistente administrado fuera del contenedor. |
| Repositorio | Archivos y su historial de cambios. |
| Commit | Registro identificado de cambios. |
| Branch | Línea de trabajo en Git. |
| Merge | Integración de historiales. |
| Pull Request | Propuesta de cambios para revisión e integración. |
| Token | Credencial o dato representativo utilizado por un protocolo. |
| Realm | Dominio de identidades y configuración en Keycloak. |
| Client | Aplicación registrada en el proveedor de identidad. |
| Role | Conjunto o categoría de permisos. |
| Middleware | Componente que interviene en el procesamiento de solicitudes. |
| IAM | Gestión de identidades y acceso. |
| Claim | Afirmación incluida en un token. |
| JWKS | Conjunto de claves públicas para verificar firmas. |
| Issuer | Emisor de un token. |
| Audience | Destinatario previsto de un token. |
| CORS | Política que regula solicitudes de origen cruzado en navegadores. |
| PATH | Lista de directorios para buscar ejecutables. |
| AVD | Configuración de dispositivo Android virtual. |
| ADB | Herramienta de comunicación y depuración Android. |
| Hot Reload | Aplicación de cambios de código preservando parte del estado. |
| Timeout | Límite de espera de una operación. |
| CRUD | Crear, leer, actualizar y eliminar. |
| Healthcheck | Comprobación periódica de disponibilidad de un servicio. |
| Transacción | Grupo de operaciones con garantías de consistencia. |
| Clave primaria | Identificador único de una fila. |
| Clave foránea | Referencia que relaciona filas entre tablas. |
| Idempotencia | Propiedad por la que repetir una operación no añade efectos distintos. |
